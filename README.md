# 🌐 Sahayak RAG

Sahayak is a **Retrieval-Augmented Generation (RAG)** assistant designed to combine vector search with large language models for intelligent, context-aware responses.  
This repository contains the codebase, data pipeline, and configurations for building and experimenting with RAG systems.

---

## ✨ Features
- 📄 Document chunking and embedding
- 🔎 Fast vector search powered by **Qdrant**
- 🤖 Integration with LLMs for retrieval-augmented answers
- ⚙️ Configurable pipeline for experimentation and scaling
- 🧪 Unit tests and modular design for easy extension
